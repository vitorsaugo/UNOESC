**Introdução ao Javascripts**


Atividades 

1. Faça um algoritmo que solicite o ano de nascimento de uma pessoa, calcule e mostre quantos anos de vida esta pessoa tem. 

2. Leia o salário de um funcionário, se ele ganhar até um salário mínimo conceda um aumento em seu salário de 15%, senão o aumento deve ser de apenas 8%. Ao final mostre o novo 
salário do funcionário já reajustado. 

3. Solicite a idade de uma pessoa, caso ela for menor de idade mostre a seguinte mensagem "Você é menor de idade", caso ela for maior de idade mostre "Você é maior de idade". 

4. Calcule a média aritmética das 3 notas de um aluno e mostre, além do valor da média, uma mensagem de "Aprovado", caso a média seja igual ou superior a 6, ou mensagem "Reprovado", caso contrário. 

5. Escreva um algoritmo que leia o código do item pedido, a quantidade e calcule o valor a ser pago por aquele lanche. Considere que a cada execução somente será calculado o valor de um lanche.

| **Código** | **Descrição**   | **Preço unitário** |
| :--------: | --------------- | -----------------: |
|     100    | Cachorro-quente |            R$ 5,50 |
|     101    | Bauru simples   |            R$ 6,00 |
|     102    | Bauru com ovo   |            R$ 6,50 |
|     103    | Hambúrguer      |            R$ 6,75 |
|     104    | Cheeseburger    |            R$ 7,50 |
