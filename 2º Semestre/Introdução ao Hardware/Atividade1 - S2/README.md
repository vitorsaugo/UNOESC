Esta questão consiste em colocar dois semáforos: um para os carros e outro para os pedestres do trânsito.

Materiais necessários para o projeto Semáforo de Carros e Pedestres

Um Arduino Uno ;
Uma Protoboard 830 Pontos;
Um push button;
6 Resistores de 220 Ω;
2 LED difuso vermelho;
2 LED difuso verde;
1 LED difuso amarelo.
Funcionamento
O sinal irá funcionar da seguinte maneira:

Quando o sinal do carros estiver verde ou amarelo, o sinal vermelho dos pedestres estará aceso;
Já quando o sinal vermelho do carros estiver aceso, o sinal verde dos pedestre deverá estar aceso;
Caso o botão seja pressionado, a preferência de passagem pela rua será dos pedestres por 5 segundos.
