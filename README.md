# Jornada na UNOESC

## Sobre este repositório

Este repositório foi criado para registrar minha jornada acadêmica na UNOESC, reunindo atividades, exercícios, trabalhos e projetos desenvolvidos durante o curso.

O objetivo é documentar minha evolução ao longo da graduação, mostrando os conhecimentos adquiridos, as dificuldades enfrentadas e os aprendizados construídos durante essa trajetória.

Cada arquivo presente neste repositório representa uma etapa do meu desenvolvimento acadêmico e profissional, servindo como um registro da minha caminhada na área de tecnologia.

## Objetivos

- Registrar minha evolução durante o curso;
- Praticar e aprimorar meus conhecimentos em programação;
- Guardar atividades e projetos desenvolvidos nas disciplinas;
- Acompanhar meu desenvolvimento acadêmico;
- Construir um histórico dos aprendizados adquiridos.

## Minha Jornada

Durante minha formação na UNOESC, venho desenvolvendo conhecimentos em programação, lógica computacional, desenvolvimento de soluções e ferramentas utilizadas na área de tecnologia.

Ao longo do curso, novos desafios e aprendizados serão adicionados a este repositório, representando cada etapa da minha evolução e contribuindo para minha formação profissional.

## Ferramentas e Tecnologias

Durante essa jornada serão utilizadas diferentes ferramentas e tecnologias, incluindo:

- Git e GitHub para controle e armazenamento dos projetos;
- Linguagens de programação estudadas durante o curso;
- Softwares e ferramentas utilizadas nas atividades acadêmicas.

## Sobre a UNOESC

A Universidade do Oeste de Santa Catarina (UNOESC) faz parte da minha formação acadêmica, proporcionando conhecimentos, experiências e desafios que contribuem para meu crescimento pessoal e profissional.

Este repositório é uma forma de acompanhar e registrar essa trajetória, reunindo os aprendizados construídos durante minha jornada universitária.
